# PostgreSQL Setup

The application can use PostgreSQL through the `DATABASE_URL` environment variable.

## 1. Create the database

```sql
CREATE DATABASE library_management;
```

## 2. Load the schema and demo data

From the project root:

```bash
psql -U postgres -d library_management -f database/library_management.sql
```

## 3. Configure the connection

Copy `.env.example` to `.env` and set your local PostgreSQL credentials:

```bash
cp .env.example .env
```

Example:

```env
DATABASE_URL=postgres://postgres:your_password@localhost:5432/library_management?sslmode=disable
```

The application reads `DATABASE_URL` from the environment.

## Repository mapping

- `domain.RoleMember` maps to the `Student` role in the database.
- `domain.RoleLibrarain` maps to the `Librarian` role.
- `domain.RoleSuperAdmin` maps to the `Admin` role.
- A member is represented by a user row whose role is `Student`.
- `loans.loan_id` is generated by the application.
- The application model represents an author's value as a string while the database supports the `book_authors` relationship.

See `adapters/postgres/` for the PostgreSQL repository implementations.
